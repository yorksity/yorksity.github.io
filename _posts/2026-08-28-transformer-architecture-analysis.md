Transformer 自 2017 年《Attention Is All You Need》提出以来，彻底改变了自然语言处理乃至整个深度学习领域。本文从整体结构到核心组件，剖析 Transformer 的架构设计与思想。

## 为什么需要 Transformer

在 Transformer 之前，序列建模主流是 RNN/LSTM。它们按顺序逐步处理输入，存在两个根本性问题：

- **无法并行**：时间步之间存在依赖，训练和推理都难以并行加速
- **长距离依赖**：信息在逐步传递中逐渐衰减，容易丢失远距离的关联

Transformer 用**自注意力（Self-Attention）**一次性建模任意两个位置之间的依赖，同时完全摆脱了循环结构，天然适合并行计算。

## 整体架构

Transformer 采用经典的 **编码器-解码器（Encoder-Decoder）** 结构：

```
输入 → [编码器 × N] → 潜表示 → [解码器 × N] → 输出
```

- **编码器**：由 N 个相同的层堆叠，每层包含多头自注意力 + 前馈网络
- **解码器**：同样堆叠 N 层，但额外包含一个**交叉注意力**子层，用于关注编码器输出

每个子层之后都接 **残差连接（Residual Connection）** 和 **层归一化（Layer Normalization）**，公式为：

```
SubLayer(x) = LayerNorm(x + SubLayer(x))
```

## 核心组件详解

### 1. 位置编码（Positional Encoding）

由于注意力机制本身对位置不敏感，需要显式注入位置信息。原论文使用正弦/余弦函数：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
```

位置编码与词向量相加后送入模型，使模型能感知 token 的先后顺序。

### 2. 自注意力（Self-Attention）

自注意力让每个 token 都能"看到"序列中的所有 token，并根据相关性分配权重。核心是 **Query/Key/Value** 三元组：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

其中除以 `√d_k` 是为了防止点积过大导致 softmax 梯度消失。

### 3. 多头注意力（Multi-Head Attention）

单一的注意力只能捕捉一种关联模式。多头机制将 Q/K/V 线性投影到多个子空间，并行计算多组注意力，再拼接结果：

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W^O
```

不同头可以关注到不同的句法、语义关系，例如有的头关注指代，有的头关注修饰关系。

### 4. 前馈网络（Feed-Forward Network）

每个位置独立地经过一个两层 MLP：

```
FFN(x) = max(0, xW_1 + b_1) W_2 + b_2
```

注意力负责"混合"信息，而 FFN 负责对每个位置做非线性变换，两者交替构成了信息处理的主干。

### 5. 掩码机制

- **Padding Mask**：屏蔽填充位置，防止其参与注意力计算
- **Look-ahead Mask**：解码器中的自注意力使用上三角掩码，确保第 t 个位置只能看到前 t−1 个位置，维持自回归生成

## 为什么 Transformer 如此强大

1. **高度并行**：注意力矩阵可一次性计算，训练速度远超 RNN
2. **直接长距离依赖**：任意两位置距离为 O(1)，不随序列增长衰减
3. **良好的归纳偏置**：多头注意力提供了灵活的关联建模能力
4. **可扩展性强**：模型规模扩大后性能持续提升，催生了 GPT、BERT 等大规模预训练模型

## 后续演进

Transformer 催生了两大主流方向：

- **仅编码器**：BERT 等，擅长理解类任务
- **仅解码器**：GPT 系列等，擅长生成类任务

此外还有稀疏注意力、线性注意力、状态空间模型（如 Mamba）等改进方向，试图在保持性能的同时降低注意力 O(n²) 的计算复杂度。

## 结语

Transformer 的核心思想简洁而深刻：用注意力取代循环，用并行换取速度。理解它的运作机制，是理解当代大语言模型的起点。
